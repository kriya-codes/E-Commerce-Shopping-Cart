# E-Commerce Shopping Cart

A Java-based E-Commerce Shopping Cart project demonstrating object-oriented programming, shopping cart operations, discount strategies, and order processing.

## Features

- Product management
- Shopping cart operations
- Fixed and percentage-based discounts
- Order processing
- File handling for product and order data

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- File Handling

## Project Structure

- `Main.java` – Application entry point
- `Product.java` – Product-related operations
- `Cart.java` – Shopping cart functionality
- `Discount.java` – Discount abstraction
- `FixedDiscount.java` – Fixed-amount discount
- `PercentageDiscount.java` – Percentage-based discount
- `OrderProcessor.java` – Order processing
- `FileManager.java` – File operations
- `products.txt` – Product data
- `orders.txt` – Order data

## How to Run

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Compile the Java files using the appropriate command for your project.
5. Run the main class.

## Purpose

This project was developed to practice Java programming, object-oriented design, file handling, and basic e-commerce functionality.
